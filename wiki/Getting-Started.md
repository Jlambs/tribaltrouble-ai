# Getting Started

## Where to get the game

| Source | Notes |
|---|---|
| [Steam: Tribal Trouble: Resurrected](https://store.steampowered.com/app/3945720/Tribal_Trouble_Resurrected/) | The easiest option. Automatic updates, achievements and cloud saves. |
| [tribaltrouble.org](https://tribaltrouble.org) | Direct downloads. |
| [GitHub releases](https://github.com/OmarAMokhtar/tribaltrouble/releases) | Builds straight from the project. |

## Installing builds from outside Steam

Builds downloaded outside Steam are not code-signed, so your operating system will warn you the
first time you run them.

- **Windows:** run `TribalTrouble.exe`. When Windows Defender shows a warning, click
  **More info → Run anyway**.
- **macOS:** open the application. When macOS says it can't verify it and suggests moving it to
  the trash, click **Done**, then go to **System Settings → Privacy & Security** and click
  **Open Anyway**.
- **Linux:** run `TribalTrouble-x86_64.AppImage`. You may need to mark it executable first:

```bash
chmod +x TribalTrouble-x86_64.AppImage
```

## Your first hour

1. **Play the [Tutorial](Tutorial.md).** Six short lessons cover the camera, building, the
   economy, towers and the Chieftain.
2. **Play a skirmish against the Easy AI.** Main menu → **Single player**, pick a small
   island. See [Game Setup](Game-Setup.md).
3. **Start the [Viking Campaign](Viking-Campaign.md)** on Easy or Normal.
4. **Read the [Strategy Guide](Strategy-Guide.md)**, then try [online play](Multiplayer.md).

## Coming from the original game?

- Your old campaign saves still work. See [FAQ](FAQ.md#moving-my-campaign-save-to-steam) for
  moving a save into the Steam version.
- Online play works again with a new account system and a new leaderboard. See
  [Multiplayer](Multiplayer.md).
- New since the original: [ships](Ship.md) and the Archipelago map,
  [spectating](Spectating.md), advanced game settings, and more
  [accessibility options](Settings.md).
