## Oddlabs and the original release (2004)

Tribal Trouble was made by **Oddlabs**, a small independent studio from Denmark, and released
in **2004**. It was written in Java using the LWJGL library, which let it run on Windows,
macOS and Linux from one code base.

The game was sold online with a free demo. The demo's "order now" screen, which is still in
the code, lists what the full version added:

- Chieftains with special attacks
- Towers for defending your land
- Two new warrior types
- Two complete campaigns
- Your own online player profiles
- Four times larger islands
- Harder computer opponents

So the demo had only peons and rock warriors, small islands and the easiest AI.

Oddlabs ran the online matchmaking servers, with player profiles, chat rooms and rated
games. *(needs source: when the original servers shut down)*

## Open source (2014)

In **2014** the source code was released under the **GNU General Public License, version 2**,
which made it possible for the community to keep the game running.

## Restoration

Contributor **bondolo** led a restoration fork that modernised the code and added
accessibility features: UI magnification, a high-contrast filter, colour-vision correction,
editable team colours, keyboard remapping, and team-colour overlays on units and buildings.
That fork remains the place to go for the pure restoration experience.

## Tribal Trouble: Resurrected

A community fork built on the restoration work set out to:

1. Bring the game back online for everyone, as it originally played.
2. Make it easy to build the game and contribute to it.
3. Remaster and modernise the graphics.
4. Add new features.

It is released on **Steam as *Tribal Trouble: Resurrected***, and on
[tribaltrouble.org](https://tribaltrouble.org) and GitHub. *(needs source: Steam release
date)*

Notable additions in *Resurrected* include:

| Feature | Notes |
|---|---|
| Online play restored | New matchmaking and chat servers |
| Steam integration | Achievements, rich presence, Steam Cloud saves |
| OpenSkill leaderboard | Rating system for online games (mid-2026) |
| [Ships](Ship.md) and the Archipelago map | Naval transport and combat (August–September 2026) |
| [Spectating](Spectating.md) | Watch games in progress (September 2026) |
| Advanced game settings | Max units, starting units, max buildings, boats on/off (September 2026) |
| Discord bot | Chat relay and `/matches`, `/profile`, `/streaks` commands (September 2026) |
| Community translations | Translations managed through a shared spreadsheet |
