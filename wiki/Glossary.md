# Glossary

Terms used in the game, on this wiki and in the community.

| Term | Meaning |
|---|---|
| **Archipelago** | *Resurrected* map type made of several islands. Players start at sea on [ships](Ship.md). |
| **Armory** | Building that stores resources and makes and hands out weapons. See [Armory](Armory.md). |
| **Attack-move** | Giving the Attack order on empty ground, so units fight anything they meet on the way. |
| **Beacon** | A map marker that alerts your team (default **Ctrl+B**, then click). |
| **Bounce** | A chicken weapon jumping to a second enemy after a hit. See [Chicken Warrior](Chicken-Warrior.md#bouncing). |
| **Chicken** | Short for [Tropical Chicken](Resources.md#tropical-chicken), the fourth resource. Also short for a chicken warrior. |
| **Chieftain** | The tribe's hero and spellcaster. See [Chieftain](Chieftain.md). |
| **Crackling Cloud** | Native spell 2: a hunting thundercloud. See [Magic](Magic.md#crackling-cloud). |
| **Defense** | A unit's chance to shrug off a hit that would otherwise land. See [Combat Mechanics](Combat-Mechanics.md#defense). |
| **Deploy** | Sending units out of a building; at an Armory, arming peons as warriors. |
| **Event log** | The per-session recording the game writes, which can be replayed. See [FAQ](FAQ.md). |
| **Garrison** | The one warrior inside a [Tower](Tower.md). |
| **High ground** | Being higher than your target, worth up to +25 percentage points of hit chance. |
| **Lur** | The long horn the Viking Chieftain blows for the Toot and the Roar. |
| **Map code** | A code shown after a game that identifies the generated island, so it can be played again. |
| **Map Mode** | The zoomed-out overview of the whole island (default **Space** or numpad 5). |
| **OpenSkill** | The rating system behind the *Resurrected* online leaderboard. See [Multiplayer](Multiplayer.md). |
| **Peon** | The worker unit. See [Peon](Peon.md). |
| **Peon-seconds** | Workshop time: one peon inside an Armory works off one peon-second per second. |
| **Quarters** | The building that breeds peons and trains the Chieftain. See [Quarters](Quarters.md). |
| **Rally point** | Where units leaving a building go. |
| **Ravaging Roar** | Viking spell 2: a damaging shockwave. See [Magic](Magic.md#ravaging-roar). |
| **Resurrected** | *Tribal Trouble: Resurrected*, the community-maintained version on Steam, and features added in it. |
| **Roster** | In the campaigns, the units you carry from island to island. |
| **Rubber** | The name the game's code uses for Tropical Chicken. "Rubber warrior" = chicken warrior. |
| **Status value** | How much a unit counts towards the tribe-strength comparison. See [Units](Units.md#unit-value). |
| **Stinking Stew** | Native spell 1: a poison cloud. See [Magic](Magic.md#stinking-stew). |
| **Stun** | Frozen by the Terrifying Toot; stunned units can't act and have no defense. |
| **Terrifying Toot** | Viking spell 1: a stun. See [Magic](Magic.md#terrifying-toot). |
| **Tower** | Defensive building for one warrior. See [Tower](Tower.md). |
| **Transport** | Sending peons out of an Armory carrying resources from its stock. |
| **Xarrr** | The thunder god of the Native islands. |
